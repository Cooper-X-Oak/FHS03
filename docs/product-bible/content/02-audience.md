# 02 用户层 Audience

用户层定义“写给谁看”。FHS 的客户约 80% 是经销商、贸易商、配件商和系统集成商，约 20% 是终端工厂。网站默认对 B2B 采购者说话，而不是对终端用户。

## 2.1 ICP 理想客户画像

`已定`（地区待确认）

**理想客户是需要持续、多品类采购过滤产品的海外 B2B 买家。**网站内容、转化入口和询盘跟进的优先级，都按下表判断。

| 维度 | 理想 | 可以接 | 暂不优先 |
| --- | --- | --- | --- |
| 客户类型 | 经销商、贸易商、配件商、系统集成商、工程商 | 酒类、饮料、印刷等终端工厂 | 个人消费者 |
| 采购内容 | 5 个核心品类，多品类、可复购 | 单一品类但会复购 | 实验室零碎耗材、泵等非核心配件 |
| 采购方式 | 持续补货或按项目批量 | 先样品后批量 | 一次性零售量 |
| 替代需求 | 替代任何品牌 | 有型号或照片，信息不全但愿意沟通 | 只接受原厂正品、要原厂授权文件 |
| 地区 | `待确认`：主要市场 | — | — |

**客户结构**

| 客户类型 | 占比 | 特点 | 英文称呼 |
| --- | --- | --- | --- |
| 经销商、贸易商、配件商 | 与下一类合计约 80% | 过滤产品经销商、喷码机及陶瓷喷码机配件商、啤酒设备商等，类型多样，不能局限 | distributors, resellers, trading companies |
| 系统集成商、工程商 | 同上 | 如水处理整套设备商，自己不制造组件，买回来做系统 | system integrators, engineering contractors |
| 终端工厂 | 约 20%，利润好 | 啤酒厂、葡萄酒厂、饮料厂、印刷厂等 | 按行业称呼，如 breweries, wineries |

> [!WARNING]
> 不要使用 equipment maker 描述系统集成商：这是中式英文，而且意思不对，他们自己不制造设备。

## 2.2 Buyer Personas 买家画像

以下是虚构的代表人物，用来在写内容时想象读者，不代表真实客户。

### Persona A：Mark，过滤产品经销商的采购负责人

| 项目 | 内容 |
| --- | --- |
| 身份 | 中小型工业品经销商，过滤产品是其中一条线，下游是当地工厂 |
| 目标 | 用更好的价格补货、扩充品类、保住转售利润 |
| 痛点 | 品牌货利润被压薄；以前试过中国供应商，质量和沟通踩过坑 |
| 搜索方式 | 产品名 + wholesale / supplier / China；用图片搜索找同款 |
| 筛选方式 | 一次问很多家，先看价格和回复速度 |
| 想在网站看到 | 要的品类有没有、实拍图、规格范围、能否混批、起订量、能否中性包装 |
| 顾虑 | 质量会不会忽好忽坏？出了问题找谁？ |
| 询价触发点 | 看到自己要的产品，而且联系门槛很低 |

### Persona B：Ahmed，水处理系统集成商的项目采购

| 项目 | 内容 |
| --- | --- |
| 身份 | 做水处理整套系统的公司，按项目采购滤壳、滤芯、滤袋、膜等组件 |
| 目标 | 按设计规格把组件配齐、控制成本、按项目时间交付 |
| 痛点 | 多处采购费时；规格对不上导致返工；交期拖慢项目 |
| 搜索方式 | 具体组件和规格，如 316L bag filter housing、high flow cartridge 40 inch |
| 筛选方式 | 带着图纸或规格清单询价，比较报价完整度和交期 |
| 想在网站看到 | 品类配得齐、规格范围、能否按清单报价、交期怎么算 |
| 顾虑 | 规格匹配会不会出错？急单能不能保证？ |
| 询价触发点 | 确认可以“把清单发过来，一次报齐” |

### Persona C：Laura，啤酒厂的维护或采购经理

| 项目 | 内容 |
| --- | --- |
| 身份 | 中型啤酒厂或饮料厂，负责生产线耗材 |
| 目标 | 稳定替换现有滤芯、滤膜，降低成本，不影响产品质量 |
| 痛点 | 原厂贵、交期长；换供应商怕影响产品和审核 |
| 搜索方式 | 现有品牌型号 + replacement；brewery filtration 等应用词 |
| 筛选方式 | 先要样品测试，再看价格和稳定性 |
| 想在网站看到 | 能否按现有型号替换、食品接触相关文件、样品政策、懂啤酒工况 |
| 顾虑 | 替代品会不会影响口感和稳定性？文件够不够应付审核？ |
| 询价触发点 | 看到“发来现有型号或照片，先寄样品测试” |

## 2.3 Jobs-to-be-Done 待完成任务

用“当……时，我想……，以便……”描述每类买家真正要完成的任务。内容和转化设计要直接服务这些任务。

| 买家 | 当…… | 我想…… | 以便…… |
| --- | --- | --- | --- |
| 经销商 | 下游客户要一款我没有的过滤产品 | 快速找到能供货、价格有空间的来源 | 接住订单并赚到差价 |
| 经销商 | 现有货源涨价或断货 | 找一个品类全、能长期合作的替代货源 | 保持供货稳定和利润 |
| 系统集成商 | 拿到一个新项目的设计清单 | 一次把组件按规格配齐并拿到完整报价 | 准确报价并按时交付项目 |
| 终端工厂 | 原厂耗材太贵或交期太长 | 找到可以直接替换的产品并先测试 | 降低成本又不影响生产 |
| 所有买家 | 只有旧件照片或不完整的型号 | 让供应商帮我确认规格 | 不用自己研究就能拿到报价 |

## 2.4 Customer Journey Map 采购旅程地图

```mermaid
flowchart LR
  J1["1 触发<br/>补货、项目、换供应商"] --> J2["2 搜索<br/>关键词、图片搜索"]
  J2 --> J3["3 浏览<br/>产品、规格、实拍图"]
  J3 --> J4["4 询价<br/>同时问多家"]
  J4 --> J5["5 筛选<br/>价格、回复速度、沟通"]
  J5 --> J6["6 样品或小单"]
  J6 --> J7["7 长期合作<br/>复购、扩品类"]
```

| 阶段 | 买家在做什么 | 买家的问题 | 网站的任务 | 负责章节 |
| --- | --- | --- | --- | --- |
| 1 触发 | 出现采购需求 | 去哪里找？ | — | — |
| 2 搜索 | 搜产品名、型号、应用词，或用图片搜同款 | 谁有这个产品？ | 被找到：关键词与图片都能出现 | 05、06、08 |
| 3 浏览 | 看产品页、实拍图、规格范围 | 他们真的有吗？靠谱吗？ | 一眼确认“有我要的”，并建立基本信任 | 03、04、05 |
| 4 询价 | 同时向多家发询价 | 怎么最快拿到报价？ | 联系门槛最低、信息一次给全 | 07 |
| 5 筛选 | 比价格、比回复速度和沟通 | 谁更值得继续谈？ | 交给 Nina：快速回复、专业沟通 | 07.5 |
| 6 样品 | 测试样品或下小单 | 质量是否稳定？ | 样品政策清楚 | 03 |
| 7 合作 | 复购、扩展品类 | 能不能长期依赖？ | 品类覆盖与稳定供货 | 01.4 |

**关键洞察**：采购者在第 4 步同时问很多家，网站要赢的不是“说服”，而是**进入第一批询价名单**。说服发生在第 5 步，由 Nina 完成。

## 2.5 Search Intent Map 搜索意图地图

| 意图类型 | 典型搜索 | 主要买家 | 承接页面类型 | 转化动作 |
| --- | --- | --- | --- | --- |
| 采购 Transactional | filter cartridge supplier China、wholesale filter bags | 经销商 | 产品页、客户类型页 | 发型号或需求，询价 |
| 规格 Specification | 316L bag filter housing、40 inch high flow cartridge | 系统集成商 | 产品页 | 发清单，一次报齐 |
| 替代 Replacement | pall filter cartridge replacement、某型号 + equivalent | 终端工厂、经销商 | 品牌替代页、替代总页 | 发现有型号或照片 |
| 应用 Application | brewery filtration、juice filtration | 终端工厂、集成商 | 行业应用页 | 发工况，推荐方案 |
| 知识 Informational | filter micron rating、bag vs cartridge filter | 所有人（早期） | 知识文章 | 引导到产品页或询价 |
| 图片 Visual | 用产品照片搜同款 | 经销商、终端工厂 | 产品页图片 | 从图片进入产品页 |

> [!NOTE]
> 经销商和系统集成商通常不会搜“我是经销商”，而是搜产品名加 wholesale、bulk、OEM、supplier。研究结果印证了这一点：系统集成商的采购表达查不到搜索量，经销商主词 “wholesale filter cartridges” 也缺数据。**结论 `已定`：客户类型页（`distributors`、`oem`）以业务入口为主，承接开发信、LinkedIn 等主动获客的落地，不以搜索流量为目标。**
