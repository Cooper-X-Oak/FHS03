# R7 综合结论与决策

**这个细分市场的采购搜索量小、竞争弱，真正的门槛是产品资料的扎实程度，而不是内容规模。**FHS 应该先拿下中国网站已经证明能排上去的品类词，用电镀做第一个主题集群，把品牌替代页当作询价入口而不是 SEO 主攻方向。 `分析判断`

> [!NOTE]
> 本章综合 R0–R6 的数据给出决策建议，是分析判断，不是新的数据。样本量小（模板对标 6 家以内，部分模板只有 1–2 家），结论应理解为方向性判断。

## 1. 市场：主战场在欧美经销商手里，中国网站在“滤芯、滤膜、知识”上更容易排上去

当前 59 组主关键词的 570 个前十席位中，欧美经销商类占 30.2%，资讯目录社媒占 19.1%，中国工厂或品牌占 15.3%，欧美原厂占 14.7%。 `工具数据`

**按意图看，中国网站的机会分布很不均匀：**

| 意图 | 中国工厂或品牌占前十 | 前十主导者 | 对 FHS 的含义 |
| --- | ---: | --- | --- |
| 知识 | 20.0% | 资讯目录社媒 35% | 中国网站能排上去，但要选与采购相关的知识题 |
| 采购 | 18.4% | 欧美经销商 38.8% | 主战场；拼的是产品资料完整度 |
| 规格 | 15.0% | 欧美经销商 36.7% | 规格类知识（如 micron rating）流量真实 |
| 应用 | 13.0% | 资讯目录社媒 27% | 行业页要靠懂工况取胜 |
| 替代 | 3.75% | 欧美原厂 42.5% | 原厂自己占据替代搜索，FHS 很难靠 SEO 抢 |

**按品类看：**滤芯（20%）和滤膜（23%）是中国网站最容易进入的品类；滤壳（10%）和滤袋（5%）的前十被欧美经销商的目录型网站占据（分别 53% 和 45%）。

**已经被验证“中国网站能赢”的关键词组**（前十中国网站 ≥ 3 个）：PE 烧结滤芯 9 个、高流量滤芯 6 个、喷码机滤芯 5 个、PES/PTFE/PVDF 对比 5 个、烧结金属 4 个、电镀过滤问题 4 个、PES 滤芯 3 个、工业滤纸 3 个、通用工业液体过滤 3 个、绝对与名义精度 3 个。这些是 FHS 最快能见效的位置。 `工具数据`

## 2. 对手：大流量不等于采购流量，核心采购流量全行业都很小

| 对手 | 全站流量估算 | 样本核心采购流量 | 核心流量主要来自 |
| --- | ---: | ---: | --- |
| commercialfiltrationsupply.com | 6,184 | 586 | 滤芯品类页（filtration cartridges 第 1 名） |
| membrane-solutions.com | 12,350 | 539 | PTFE 膜产品页 |
| brotherfiltration.com | 14,719 | 265 | 少量产品页 |
| filsonfilters.com | 2,202 | 159 | CUNO 滤壳替代页（第 1 名）、烧结滤芯 |
| newater.net | 694 | 27 | PP 滤芯解释页 |
| hongtekfiltration.com | 204 | 22 | 熔喷滤芯文章、PVDF 滤壳 |

`工具数据`（样本为各家按流量排序的前 200 个词，核心流量为估算值）

三条结论：

1. **对手的大流量来自与采购无关的内容。** Brother 最大流量页是“纯净水和蒸馏水的区别”，sinteredfilter.net 是“金属熔点和密度”。FHS 不追这类流量，也不比文章数量。
2. **核心采购流量真正来自扎实的品类页和产品页。** 拿到核心流量最多的是 CFS 的滤芯品类页和 MS 的 PTFE 膜产品页，证明“产品资料做透”比“文章写多”更有效。
3. **品牌替代要用“品牌 + 产品类型”的组合词。** Filson 靠 “cuno filter housing”（月搜索 140）排第 1，而泛词 “pentair filter cartridge”、“3m filter cartridge” 的结果被泳池家用和呼吸防护占据。替代页的 SEO 目标应改为具体组合词。 `分析判断`

**预期管理：**最强的中国对手，样本里的核心采购流量也只有每月几百。FHS 上线并成熟后，合理预期是每月几十到一两百个有采购意图的访问，带来个位数到十几个询盘。这与“少而有效”的目标一致，但需要提前跟 Nina 对齐，主动获客仍是另一条腿。 `分析判断`

## 3. 模板：门槛人人都有，真正的差异在几个“没人做”的模块

在所有模板里反复出现、几乎没有竞品做的模块（判定为“补”）：

| 模块 | 竞品情况 | FHS 做法 |
| --- | --- | --- |
| M04 细节图、尺寸参照图 | 产品页 0/6 | 端盖、接口、尺寸标注图，帮助采购核对 |
| M10 替代或兼容说明 | 产品页 0/6 | 产品页写明可替代的品牌系列（只列已核验的） |
| M11 商标免责声明 | 所有模板 0 | 替代页和产品页统一加 |
| M21 具名对接人 | 所有模板 0 | 每页联系模块具名 |
| M23 长尾入口 | 产品页 1/6 | “没找到也可以发照片” |
| M26 按客户类型分流 | 首页 0/6 | 首页给经销商、系统集成商、终端工厂各自入口 |
| M09 选型指南 | 产品页 0/6 | 产品页内嵌“怎么选”，不只放到知识文章 |

**跟**（门槛）：面包屑、首段直接回答意图、产品图库、主行动按钮、结构化数据，在产品页和首页都是 5–6 家具备。

**超**：询价表单 6/6 家都有，但只有 2 家做得好（字段多、无上传）。FHS 用最少必填 + 上传照片超过它们。

**避**：首页和关于页 5–6 家都堆规模数字（年限、国家数、客户数）。FHS 只放能兑现的数字。

## 4. 对 Codex 优先级的修正

Codex 的页面优先级主要按“KD 是否在阈值内”打分，导致几个业务上最重要的页面因为缺 KD 数据被降到 P2。结合 Nina 的业务备注和“中国网站已能排上去”的证据，建议调整为三个批次：

### 第一批：最快见效，也是 Nina 的主力产品

| 页面 | 原优先级 | 调整理由 |
| --- | --- | --- |
| `high-flow` 高流量滤芯 | P1 | 前十已有 6 个中国网站；有确认的内容缺口（1 与 20 微米取舍） |
| `metal` 烧结金属滤芯 | P1 | 前十 4 个中国网站，竞争强度 1 |
| `other-cartridges` PE 烧结滤芯 | P2 → **P1** | 前十 9 个中国网站，几乎全是中国网站的赛道 |
| `pes` PES 滤芯 | P2 → **P1** | 前十 3 个中国网站 |
| `depth` 深层滤芯 | P1 | Nina：电镀客户和欧洲经销商的走量产品 |
| `plating-paper` 电镀滤纸 | P2 → **P1** | Nina：电镀行业用量第二大的产品 |
| `pp-bag-housings` PP 袋式滤壳 | P2 → **P1** | Nina：占滤壳业务约 80% |
| `inkjet` 喷码机滤芯 | P2 → **P1** | 前十 5 个中国网站；喷码机配件商是核心客户群 |
| `cartridges` 滤芯总页 | P1 | 品类页是核心采购流量的主要来源 |
| `distributors`、`oem` 客户类型页 | P1 | 承接主动获客的落地，不依赖搜索 |
| `quote`、`catalog` | P1 | 转化入口 |

### 第二批：搜索量大，但前十被欧美经销商目录占据

`housings`（1,300）、`bag-housings`（480）、`cartridge-housings`、`bags`、`liquid-bags`、`capsule`、`ptfe`、`pleated`、`filter-paper`，以及 `membranes`、`ro-membranes`（待 IA-Q1 决定是否升级）。这一批必须把规格、尺寸图、选型做得比目录网站更好，才有机会。

### 第三批：行业页、知识页与替代页

- **电镀主题集群提前到第一批末尾**：`electroplating`（Nina 标注的战略重点）+ `plating-problems`（前十 4 个中国网站）+ 深层滤芯、电镀滤纸、阳极袋、PP/PVDF 滤壳，形成一个完整的主题集群。
- 行业页：`beer`（210）、`soft-drinks`（170）、`wine`、`water`、`chemical`。
- 知识页：优先 `micron-rating`（规格类知识有真实流量）、`absolute-vs-nominal`、`bag-sizes`。
- 替代页：作为询价入口建设；SEO 只攻“品牌 + 产品类型”的组合词，泛品牌词（Pentair、3M、Millipore）不投入。

## 5. 对待确认事项的影响

- **IA-Q4（Manufacturer 定位）有了数据依据：**首页主词 “industrial filtration manufacturer” 月搜索量只有 30、KD 53，几乎没有 SEO 价值。保留“制造商”的说法换不来流量，却会与“多厂匹配的采购合作伙伴”定位冲突。建议去掉 Manufacturer 定位。
- **IA-Q1（滤膜是否完整建设）：**`membrane filter` 月搜索 1,600、前十已有 2 个中国网站，`ro membrane` 2,900 但前十没有中国网站。建议 `membranes` 升级为完整建设，`ro-membranes` 维持骨架，用来把 RO 流量引向前置过滤产品。
